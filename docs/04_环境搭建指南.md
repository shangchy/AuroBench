# 04 环境搭建指南

> 本地与云环境的搭建方法、系统构成与一键部署。从零搭建可复现的 LLM 运行与评测环境。

## 1. 系统构成

### 1.1 技术架构（分层）

```
┌────────────────────────────────────────────────────┐
│                     应用层                          │
│   评测脚本 (Python)         部署脚本 (PowerShell)     │
│   main.py / runner.py       setup.ps1 / setup.bat   │
└──────────────────────┬─────────────────────────────┘
                       │ HTTP REST (11434)
┌──────────────────────▼─────────────────────────────┐
│               推理服务层 (ollama)                    │
│   /api/generate   /api/tags   /api/pull             │
│   模型加载 · 量化推理 · 请求调度 · 资源管理           │
└──────────────────────┬─────────────────────────────┘
                       │ 文件读取 (GGUF 权重)
┌──────────────────────▼─────────────────────────────┐
│            模型存储层（OLLAMA_MODELS 指定目录）       │
│   blobs/ · manifests/ · manifests-v2/ · metadata/    │
└──────────────────────┬─────────────────────────────┘
                       │ 计算资源
┌──────────────────────▼─────────────────────────────┐
│                   硬件层（CPU / GPU 推理）           │
└────────────────────────────────────────────────────┘
```

### 1.2 硬件要求

| 组件 | 建议配置 | 说明 |
|------|----------|------|
| CPU | 多核（≥4C8T） | 承担 CPU 推理计算 |
| 内存 | 7B 模型建议 ≥16GB | 支持模型加载与推理 |
| GPU | 可选 | 有 GPU 加速，无则走 CPU |
| 磁盘 | 预留 ≥20GB（建议非系统盘） | 存放模型 |

### 1.3 软件构成

| 组件 | 职责 |
|------|------|
| ollama | 推理运行时、HTTP API |
| Python | 评测脚本环境 |
| requests | HTTP 客户端 |
| 评测脚本 | 生成、打分、报告 |
| 部署脚本 | 一键部署 |

## 2. 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows 10/11 |
| Python | 3.10+ |
| 内存 | 7B 模型建议 ≥16GB |
| GPU | 可选；无 GPU 走 CPU |
| 磁盘 | 模型 13~17GB，建议非系统盘 |
| 网络 | 首次需联网下载模型 |

## 3. 安装 ollama

```bat
winget install --id Ollama.Ollama -e --accept-source-agreements --accept-package-agreements
```

或从 `https://ollama.com/download` 下载安装包。验证：

```bat
ollama --version
```

## 4. 下载模型

```bat
ollama pull qwen2.5:1.5b
ollama pull qwen2.5:3b
ollama pull qwen2.5:7b
ollama pull deepseek-r1:1.5b
ollama pull llama3.2:3b
ollama pull gemma2:2b
ollama pull glm4:9b
ollama pull huihui_ai/seed-coder-abliterate
ollama pull qwen3-embedding:0.6b
```

**模型构成与选型**：

| 模型 | 大小 | 角色 |
|------|------|------|
| qwen2.5:1.5b / 3b | 1~2GB | 轻量、中文好 |
| qwen2.5:7b | 4.7GB | 质量较高 + 裁判模型 |
| deepseek-r1:1.5b | 1.1GB | 推理型任务 |
| llama3.2:3b | 2.0GB | 英文任务 |
| gemma2:2b | 1.6GB | 通用任务 |
| glm4:9b | 5.5GB | 智谱 GLM 家族 |
| Seed-Coder-8B（社区 abliterate 版） | 5.1GB | 字节 Seed 家族（代码） |
| qwen3-embedding:0.6b | 639MB | 向量化 / RAG |

## 5. 模型存储配置

通过 `OLLAMA_MODELS` 环境变量指定模型存储目录（默认在用户目录，可改为非系统盘）：

```powershell
setx OLLAMA_MODELS "D:\ollama\models"
```

> 设置后需**注销重新登录**或重启，使环境变量对 ollama 生效。

## 6. 验证环境

```bat
ollama list
ollama run qwen2.5:3b "你好，请自我介绍"
```

## 7. 对外服务（简要）

- **LiteLLM 网关**：`pip install 'litellm[proxy]'`，配置 `model_list` 接入 ollama，`litellm --config ... --port 4000`。
- **MCP**：`mcp`（FastMCP）实现工具，stdio + HTTP 双传输。

详细设计见《07 对外服务设计》。

## 8. 一键部署

`deploy/setup.ps1` + `setup.bat` 封装「装 ollama → 配置模型目录 → 拉模型 → 装依赖 → 部署脚本」全流程，双击 `setup.bat` 复现环境。分发内容：`deploy\` 与 `scripts\eval\`。

## 9. 常见问题

| 问题 | 处理 |
|------|------|
| 模型下载慢 | 改用内网镜像或直接拷贝模型目录 |
| `ollama list` 为空 | 检查 `OLLAMA_MODELS` 是否已生效（需重登） |
| 7B 模型速度慢 | 无 GPU 属正常；改用 1.5b/3b 模型 |
| LiteLLM 连接错误 | 确认 ollama 已启动、`api_base` 指向 11434 |
| 端口占用 | 修改 LiteLLM `--port` 或 ollama 端口 |
