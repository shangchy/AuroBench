## 8. 依赖关系与关键路径

```
阶段一(本地) ──M1──▶ 阶段二(DeepSeek) ──M2──▶ 阶段三(多模型) ──M3──▶ 决策
        │                    │                    │
     脚本框架              成本基线            最终结论
      Agent v0           Agent 基线
```

- **关键路径**：本地搭建 → 方法论冻结 → 云 DeepSeek → 多模型 → 结论。
- **决策门**：M1（本地评审）、M2（单模型评审）、M3（最终决策），未通过不进入下一阶段，控制成本风险。
