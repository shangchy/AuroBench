# 00 需求文档

> 项目需求的来源、目标、范围与约束。原始依据：`中国製モデル検証計画-v1.0.pptx`。

## 1. 项目背景

针对包含 DeepSeek 在内的中国产高性能 AI 模型，从 **功能** 与 **成本** 两个维度推进验证，为是否导入、以何种形态（SaaS / 本地 / 云）导入提供决策依据。

## 2. 需求目标

| 目标 | 说明 |
|------|------|
| 能力验证 | 判定中国产大模型的功能满足度与质量差距 |
| 成本测算 | 量化云上满血大模型的 TCO，支撑投资决策 |
| 评测体系 | 建立「脚本 + Agent」双通道、可复现的评测方法论 |
| 导入建议 | 输出推荐模型、部署形态与导入路线图 |

## 3. 验证对象

### 3.1 比较维度

1. SaaS 版 / 本地版 的比较
2. 美国系 LLM / 中国系 LLM 的比较
3. 最新模型 / 旧模型 的比较
4. Smartrans 转换精度（以实际业务题材测试）

### 3.2 模型清单

| 阶段 | 对象 |
|------|------|
| 本地小模型 | qwen2.5 1.5b/3b/7b、deepseek-r1:1.5b、llama3.2:3b、gemma2:2b、glm4:9b、Seed-Coder-8B（社区版） |
| 云满血大模型 | DeepSeek v4、Qwen 3.8、GLM 5.3（满血版） |

## 4. 验证范围（三阶段）

| 阶段 | 名称 | 环境 |
|------|------|------|
| 一 | 本地小模型搭建及评测 | 本地（ollama，CPU） |
| 二 | 云环境搭建 DeepSeek 大模型 | 云（阿里/腾讯/华为） |
| 三 | 多个满血大模型横向对比 | 云 |

## 5. 评测需求（双方式）

| 方式 | 要求 |
|------|------|
| 脚本评测 | 客观量化：规则 + LLM 裁判打分，覆盖推理/代码/问答/翻译/指令遵循/长文本/多轮对话/信息抽取 |
| AI 应用 / Agent 评测 | 真实场景：通用 Agent（RAG+工具+多轮）+ Smartrans 业务场景 |

## 6. 课题与约束

- 缺乏 LLM 测试方面的实绩与经验规范
- 人员资源不足
- 已向信华信集团确认，对方亦无相关调查经验
- 需考虑**外部专家采购**（待定）

## 7. 需求边界

- 验证范围以功能与成本为主，不含生产化部署与业务系统改造。
- 满血大模型评测限于云环境，本地仅做小模型可行性验证。
- 最终交付为验证结论与导入建议，不包含实际采购决策。

## 8. 验收标准

| 需求目标 | 验收标准 | 对应交付物 |
|----------|----------|-----------|
| 能力验证 | 输出各模型脚本综合分与 Agent 任务完成率 | 评测报告（03 交付物 4/5/6） |
| 成本测算 | 输出各模型 TCO 与每 token 成本 | 成本基线（03 交付物 5） |
| 评测体系 | 脚本 + Agent 双通道可复现执行 | 评测框架（03 交付物 1/2/3） |
| 导入建议 | 输出推荐模型、部署形态与路线图 | 结论报告（03 交付物 7） |
