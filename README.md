# 中国制 LLM 模型验证项目

对含 DeepSeek 在内的中国产高性能 AI 模型，从**功能**与**成本**两个维度进行验证，为导入决策及部署形态（SaaS / 本地）提供依据。本仓库包含：项目规划文档、本地 LLM 评测环境、自研评测脚本与一键部署方案。

## 目录结构

```
AuroBench/
├── docs/                  # 项目文档（8 份编号文档）
├── scripts/
│   └── eval/              # 自研评测脚本（核心）
│       ├── main.py        #   入口
│       ├── config.py      #   配置
│       ├── questions.py   #   题集（8 维度 24 题）
│       ├── runner.py      #   生成回答（自动发现模型）
│       ├── scorer.py      #   规则 + LLM 裁判打分
│       └── report.py      #   生成报告
├── deploy/
│   ├── setup.ps1          # 一键部署逻辑
│   └── setup.bat          # 一键部署入口（双击）
├── .gitignore
└── README.md
```

## 快速开始

### 本机运行评测

```bat
cd D:\workspace\ttt\scripts\eval
python main.py
```

结果输出至 `scripts/eval/results/`（`report.md` / `report.csv`）。

### 部署到其它 Windows 机器

分发 `deploy\` 与 `scripts\eval\` 后，双击 `deploy\setup.bat`，自动完成 ollama 安装、模型下载、依赖安装与脚本部署。

## 当前评测结论（初步）

本地部署 8 个开源模型，8 维度 24 题，规则 + LLM 裁判双通道打分：

| 排名 | 模型 | 平均分 |
|------|------|--------|
| 1 | gemma2:2b | 88.0 |
| 2 | glm4:9b | 87.9 |
| 3 | qwen2.5:3b | 87.2 |
| 4 | qwen2.5:7b | 86.2 |
| 5 | qwen2.5:1.5b | 82.6 |
| 6 | Seed-Coder-8B（社区版） | 82.6 |
| 7 | llama3.2:3b | 81.6 |
| 8 | deepseek-r1:1.5b | 80.1 |

- `glm4:9b` 表现亮眼（第 2），翻译能力明显强于其他小模型
- 新增维度（多轮对话 97.1、长文本 96.2、信息抽取 89.4）小模型表现普遍较好
- 中日翻译仍是整体短板（平均 55.1 分），是后续云满血模型重点验证方向
- 详细结果见 `scripts/eval/results/report.md`
